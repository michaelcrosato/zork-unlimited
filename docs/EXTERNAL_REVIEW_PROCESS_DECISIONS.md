## Boundaries

- The cross-family cohort is an experiment, not automatic retention authority.
- Coverage is a measured nightly report for the Vitest `standard` project. It is
  not yet a percentage gate; thresholds need a stable baseline and an explicit
  choice about generated, CLI, and UI scope.
- The save/world migration-ladder deletion is owner-authorized and implemented
  as the structural v11/v10 contract. Structurally provable v10 entries with
  current IDs and causal boundaries upgrade; legacy marker kinds, quest starts
  without an approach ID, and source-hash-only local proofs fail closed because
  accepting them would restore the retired hash authority. Future incompatible
  state-shape changes still require an explicit structural version and proof;
  authored-copy changes do not.
- Performance warnings diagnose cost. They never weaken completeness, state caps,
  validator direction, or branch-protection requirements.
- Feedback compilation is currently owned by the prompted operating agent.
  `loop.sh` does not independently count reports or invoke the compiler; its
  enforced responsibility begins again at the outer verification gates.
